# Workflow Site
Site técnico e apresentação da Workflow Skill. Leia PROJECT.md e docs/implementation-plan.md.
- npm run dev: prévia local; npm run build: build de entrega; npm run lint: lint; npx tsc --noEmit: tipagem.
- app/: páginas e componentes. public/: imagens e ícone. docs/: plano e verificação.
- Texto baseado na release v0.1.0-alpha.1 de edubertin/workflow-skill. Distinguir instalação, descoberta, comportamento e estabilidade.
- Somente o agente proprietário do Sites edita este checkout e utiliza ferramentas Sites.
- Não copiar configurações pessoais, credenciais ou perfis globais. Sem métricas fictícias.
- Imagens com Imagegen; diagramas funcionais com HTML/SVG. Movimento reduzido e navegação por teclado.
- Funções próprias até 40 linhas. TypeScript estrito; sem any e sem capturas de erro silenciosas.
- Publicação/commit/push conforme autorização atual do usuário. Não alterar outros repositórios.
